# 练习与批改

练习是产生掌握证据的环节。Agent 在这里扮演出题人和阅卷人：让学习者先独立作答，再给出精确反馈、定位错因，并用变式题确认错误已经修正。题型设计原则见 [learning-design.md](learning-design.md)，掌握等级定义见 [learner-state.md](learner-state.md)。

## 1. 选题

有学习项目时，从 `00_learner_state.md` 中选择：用户指定的节点；或到期复习项、未关闭的错误记录、刚学完的单元。没有项目时，从用户给出的材料或主题出题。

每题要说得出它检验哪个节点、哪个认知动作（提取、解释、应用、辨错、迁移）；这是出题人的内部依据。检验“先判断该用什么方法”的题目，不在题面写出节点名或方法名，以免提示答案。按学习者当前等级选难度：

| 当前等级 | 题目重点 |
| --- | --- |
| 接触过 | 提取与解释：写出条件、定义、步骤，说明为什么 |
| 能提取 | 同类应用：换数字、换材料，但方法明确 |
| 能应用 | 判断与迁移：先识别该用哪个方法，或条件变化后重新判断 |
| 能迁移 | 混合题、限时题、目标任务原型题 |

每组题可以加一道比当前等级高一级的探针题；答对即构成升级证据，答错不降级。

学过的易混节点放进同一组题，按交替顺序出现，让学习者练习区分；只有专门检验区分能力时才把两个节点合进一道题。

不要从留出验收题中取题，也不要复用它们的数据、材料和题目结构。

## 2. 交互出题

- 一次发出的量以学习者一次能专注完成为限，通常 15—30 分钟。估算参考：提取题 1—3 分钟，解释题 3—5 分钟，应用或计算题 5—10 分钟。多步推导或长论述一次一题。诊断、复习和练习都按这条分批。
- 明确作答形式（数字、步骤、要点、段落）和是否限时。
- 题目发出后停下，等待学习者作答；答案和解析在作答后才给。
- 学习者卡住时，按提示阶梯逐级给：方向提示 → 关键第一步 → 部分步骤 → 完整示范。每升一级都先让学习者再试。记录用到的最高提示级。
- 学习者要求直接看答案时给出答案，并把该题记为“未独立完成”。

用户要求书面题单而不是当场练习时，生成题单文件，题目在前、答案和评分要点在后，存入 `03_practice/`。

## 3. 批改

先判对错，再看过程。对每道题给出：

1. **结论：** 正确、部分正确或错误；有评分标准时给分。结论对但理由错或不完整，记为部分正确；方向、符号类判断要核对每个因素的理由。
2. **错误位置：** 指出第一处出错的步骤、句子或判断，不只给正确答案。
3. **错因类型：**
   - 知识缺失：不知道该知识点；
   - 概念混淆：把相近概念、方法或条件混用；
   - 条件误用：方法没错，但在不满足前提时使用；
   - 步骤错误：推导、计算或操作中的具体失误；
   - 表达缺漏：意思对，但缺少得分要点、关键限定或规范表述；
   - 粗心：学习者在被指出位置后能立即自行改正。
4. **最小纠正：** 用最少的话讲清正确做法和为什么；概念性错误回到机制或定义，不只给结论。
5. **变式确认：** 对知识缺失、概念混淆和条件误用，立即给一道换了表面特征的变式题。原题考方向、符号或结论判断时，变式题同时改变符号或结构，使上一题的结论不能直接套用。变式答对才视为当场修正；仍然答错则回到相关笔记或前置节点讲解，再出题。

开放题按评分维度批改，允许多种合理答案，指出哪些维度达到、哪些缺失。不根据措辞是否与参考答案相同判分。

学习者的答案本身包含有价值的不同思路时，先判断它是否成立；成立就承认并说明与参考解法的关系。

## 4. 记录

每次批改产生新证据后、停下等待学习者作答前，先更新 `00_learner_state.md`；只发出题目而没有新作答时不写。更新内容：

- 按证据调整掌握等级（规则见 [learner-state.md](learner-state.md)）；
- 新错误写入错误记录，状态先记“待修正”；变式确认通过后改为“当场修正待复查”，等待在后续复习中复查；
- 设定下次复习日期（绝对日期）。

练习有书面价值（较长的计算、论述或用户要求保存）时，把题目、作答、批改存入 `03_practice/<日期>_<主题>.md`。

## 边界

学习者提交的是需要独立完成的受评作业或考试题时，不代写可直接提交的答案。可以批改学习者自己的作答、指出错误位置和错因、讲解相似题，并给出自检标准。
