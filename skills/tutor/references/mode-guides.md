# 六种处理模式

只读取并使用命中的模式。一个学习单元可以有一个主要模式和若干次要模式；不要为满足模板而完整展开所有模式。

## 概念与理论

应显化：

- 概念的定义、边界、上位／下位概念和近邻概念；
- 理论试图解释的问题；
- 前提、机制、变量或环节、结论及适用边界；
- 支持例、反例和条件变化后的结果；
- 不同理论的真实分歧，而非只列人物和口号。

优先使用关系图、因果链、分类树或比较表。练习要求解释“为什么”、预测条件改变后的结果、判断反例或比较两个解释。

避免：把理论压成一句结论；把相关关系写成因果；把模型内部推论写成已验证事实。

## 论证与证据

应显化：

- 研究问题或争议；
- 核心主张；
- 证据与来源；
- 从证据到主张所依赖的理由或隐含假设；
- 竞争解释、反驳、证据限制和仍未解决的问题；
- 历史时序、制度背景或文本语境中真正影响判断的内容。

案例按“问题—材料—推理—结论—边界”组织。论文可按“问题—既有解释—机制／方法—证据—结论—贡献与限制”组织，但材料不含某一项时不补造。

练习应要求标出证据、区分事实与解释、补出隐含前提、评价证据能否支持结论，或用新材料重新判断。

避免：把观点清单当作论证；用后来知识替材料中的人物发言；省略证据只保留结论。

## 定量与问题求解

应显化：

- 为什么需要该方法，它解决什么问题；
- 前提、适用条件和不适用情形；
- 公式、符号、单位或数据含义；
- 推导或解题中的关键变换与决策点；
- 至少一个完整 worked example，包含“为什么做这一步”；
- 结果校验：量纲、符号、数量级、边界值、图形或替代计算；
- 常见错法及其错误发生的位置。

对初学者使用“完整例题 → 部分步骤留空 → 独立问题”；学习者已有基础时减少重复示范，增加题型辨别、交错练习和迁移。

练习不能只换数字。至少有一道题要求先识别应使用的模型或方法，并解释选择。

避免：只列公式；不写假设；把近似写成恒等；计算结果未经复核；从转写错误中猜测符号。

## 程序与实践

应显化：

- 任务目标和完成标准；
- 先决条件、工具、材料、环境和安全／合规要求；
- 按实际依赖排列的操作步骤；
- 每个关键步骤的输入、动作、可观察输出和检查点；
- 失败信号、常见原因、最小纠正动作与停止条件；
- 最终产物、记录方式和复盘问题。

代码课程保留可运行的最小示例、输入输出、关键语句、典型报错和调试路径；实验课程保留变量、控制、测量、误差来源和数据记录要求。

练习优先采用情境任务、步骤排序、错误诊断、预测输出和独立操作检查单。

避免：从不完整材料猜测危险操作；把演示结果当作所有环境都能复现；只写“点击哪里”而不解释判断信号。

## 文本与解读

应显化：

- 原文的关键表述、术语和限定词；
- 文本的语境：作者、时代、文体、所属体系或条文结构；
- 字面意义、通行解释和有争议的解释；
- 解释所依据的原文证据和解释边界；
- 与相近文本、条文或概念的对比。

练习应组合原文定位、释义、辨析相近表述、用原文证据支持解释，以及把文本适用到新情境。答案允许多种解释时提供评价条件，不伪造唯一措辞。

避免：脱离原文复述二手解释；把一种解释写成唯一正解；释义时丢失原文的限定、不确定性或立场。

## 案例与项目

应显化：

- 真实任务、背景和利益相关者；
- 目标、约束、资源和成功标准；
- 需要作出的关键决定及可选方案；
- 每个方案的依据、权衡、风险和验证办法；
- 阶段产物、反馈点和最终评价维度；
- 案例能说明什么、不能推广到什么范围。

如果任务本身是受评作业，提供问题拆解、相似示范、自检表和反馈标准，不替学习者生成可直接提交的最终答案。

练习可要求重做决策、改变一个约束后调整方案、评价失败案例或设计验证。

避免：把开放项目伪装成唯一标准流程；只给成品不给决策过程；用单个成功案例推出普遍结论。

## 混合模式的组织

优先按知识依赖组织，而非把模式做成六个并列大章。例如一节计量课可以按：

1. 研究问题与直觉；
2. 模型及假设；
3. 推导与完整例题；
4. 对实证结果的解释和证据边界；
5. 错误诊断与迁移题。

这里同时使用概念、定量和论证模式，但读者看到的是一条连续学习路径。
