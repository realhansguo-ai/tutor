# 课程画像与路由

## 为什么不用“文科／理科”硬分类

学科名称不能直接决定学习动作。一节经济学课可能同时要求解释理论、推导公式、读取图表和评价政策；一节历史课也可能包含事实记忆、因果解释、材料论证和论文写作。分类对象应是当前**学习单元**，不是整门课的永久标签。

本 Skill 使用两个有研究基础的底层坐标，再把它们翻译成便于生成学习材料的处理模式：

1. 修订版 Bloom 分类中的知识形态：事实性、概念性、程序性、元认知知识；
2. 认知过程：记忆、理解、应用、分析、评价、创造。

六种处理模式是工程路由，不是一个被宣称为权威的课程 taxonomy。它们允许组合，作用是决定笔记中应显化什么、练习要求学习者做什么。

## 轴一：知识形态

| 知识形态 | 识别信号 | 整理重点 |
| --- | --- | --- |
| 事实性 | 术语、日期、人物、符号、规则、数据 | 精确定义、最小必要背景、辨认线索 |
| 概念性 | 分类、原理、理论、模型、机制、关系 | 边界、结构、因果或逻辑连接、反例 |
| 程序性 | 算法、步骤、方法、技术、判断流程 | 适用条件、顺序、决策点、示例、错误诊断 |
| 元认知 | 何时用什么方法、如何自检、如何判断掌握程度 | 选择策略、监控信号、失败原因、改进动作 |

不要把事实性知识一概删掉。公式、词汇、法条要点、历史时序和操作参数可能是理解与应用的必要基础。

## 轴二：认知动作

| 动作 | 可观察表现 | 合适任务 |
| --- | --- | --- |
| 记忆 | 不看材料提取信息 | 回忆、列举、标注、复述 |
| 理解 | 用自己的话建立意义 | 解释、举例、概括、比较 |
| 应用 | 在题目或情境中使用 | 计算、执行、套用并说明选择 |
| 分析 | 拆开结构和关系 | 区分、归因、找假设、读证据 |
| 评价 | 按标准作判断 | 评估论证、选择方法、指出局限 |
| 创造 | 组合知识形成新产物 | 设计、建模、写作、提出方案 |

高阶任务通常依赖必要的低阶知识，但不要把列表机械理解为所有学习都必须逐级完成。

## 六种可组合处理模式

### 1. 概念与理论

信号：大量概念、模型、原理、机制、学派或因果关系。常见于哲学、经济学、政治学、物理理论、生物机制等。

### 2. 论证与证据

信号：研究问题、主张、理由、材料、数据、解释竞争、反驳或来源评价。常见于历史、法学、社会科学、文学评论和论文阅读。

### 3. 定量与问题求解

信号：公式、推导、计算、证明、数据、图表、模型选择或题型。常见于数学、统计、计量、物理、化学和部分会计、金融课程。

### 4. 程序与实践

信号：实验、软件、代码、仪器、制作、临床／职业流程、操作标准或故障排查。重点是“能否安全、正确、可复核地完成”。

### 5. 文本与解读

信号：经典原文、法条、规范文件、文学或史料文本、术语严格的定义性文字、需要细读和释义的段落。重点是原文表述、意义、语境和解释边界。

语言习得本身（词汇积累、听说读写熟练度）依赖长期练习，不属于本 Skill；语法体系、文体知识等可陈述的部分可以按本模式学习。

### 6. 案例与项目

信号：开放问题、复杂情境、设计任务、政策案例、商业案例、研究项目或综合作品。重点是约束、决策、权衡、产物和评价标准。

具体展开要求见 [mode-guides.md](mode-guides.md)。

## 目标任务叠加层

学习项目中的目标任务（见 [goal-and-map.md](goal-and-map.md)）决定单元要支持哪类作答。考试是目标任务的一种来源；只有教学大纲、真题、评分标准或用户说明能够支持时，才标记“考试重点”。不要仅凭模型经验猜题。

| 任务 | 笔记应支持 | 练习方式 |
| --- | --- | --- |
| 识记与辨认 | 关键词、边界、易混项 | 闭卷回忆、选择项辨错 |
| 简答与解释 | 定义、机制、逻辑链、答题结构 | 限字解释、要点式答案 |
| 计算与证明 | 条件、步骤、符号、检查点 | 例题—补全题—独立题 |
| 材料与案例分析 | 证据定位、规则／理论匹配、推断边界 | 新材料迁移、依据标注 |
| 论述与写作 | 命题、结构、证据、反方和结论 | 提纲、限时段落、评分维度 |
| 操作与表现 | 流程、质量标准、安全、故障信号 | 情境演练、检查清单、复盘 |

考公、考研和职业考试不是独立知识类型。它们是目标约束：更重视考试范围、题型、时间、评分方式和跨单元检索。没有官方范围或真题时，使用通用学习资产，不宣称“命中考试”。不以考试为目的的学习同样使用此表，按目标任务中的交付物选择对应行。

## 学习者阶段调整

| 场景 | 默认调整 |
| --- | --- |
| 高中／首次学习 | 补足先修概念；降低单步信息量；从完整示例到独立练习 |
| 大学课程 | 保留理论、方法、来源与学科表达；强调模型条件和证据边界 |
| 考研／考公 | 对齐已提供的大纲、真题与评分；加强跨章节检索、辨错和限时输出 |
| 职业／资格考试 | 对齐标准、程序和情境判断；明确安全、合规与操作边界 |
| 已有基础的复习者 | 压缩背景；增加比较、迁移、错因和快速检索结构 |

## 内部画像模板

生成前在工作记录中简短填写，不必原样进入成品：

```markdown
学习者与目标：
材料范围：
主要知识形态：
目标认知动作：
主要模式：
次要模式：
目标任务：
需要的脚手架：
来源缺口与待核实项：
```

如果材料不足以判断，先做保守画像；只有不同选择会显著改变输出时再询问用户。

## 研究依据

- [修订版 Bloom 分类的综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4511057/)说明知识可区分为事实性、概念性、程序性和元认知，认知过程可表述为记忆、理解、应用、分析、评价和创造。
- [Chi 与 Wylie 的 ICAP 框架](https://doi.org/10.1080/00461520.2014.965823)区分被动、主动、建构和互动参与，支持把学习材料从“可阅读”推进到需要学习者生成解释、推断或共同建构。
- [OECD Learning Compass 2030](https://www.oecd.org/en/data/tools/oecd-learning-compass-2030.html)使用知识、技能、态度和价值观描述更宽的学习成果。本 Skill 聚焦可由课程资料支持的知识与技能；态度或价值目标只有材料明确要求时才进入，不从学科名称推断。

这些来源支持底层维度，不直接证明六种处理模式是唯一分类。模式是为跨学科学习资产生成而做的可修改工程映射。
