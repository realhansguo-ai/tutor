# 学习单元：把资料重构为可学习资产

本流程把一节课、一章、一个专题或一组材料，重构成忠于来源、便于理解、能够练习并可复习的单元笔记。课后模式先按 [after-class-mode.md](after-class-mode.md) 完成归档，再进入本流程；讲透模式在第 5 步叠加。

## 0. 连接学习项目

存在 `00_learning_plan.md` 时先读取它和 `00_learner_state.md`，确定：

- 本单元对应领域地图中的哪些节点、服务哪些目标任务；
- 学习者在这些节点上的掌握等级、错误记录和缺失前置；
- 目标任务要求的认知动作，例如只需辨认，还是要计算、论证或迁移。

已掌握且有证据的节点压缩为回顾和检索题；薄弱、前置和高权重节点展开。没有学习项目时，按 `SKILL.md` 的默认学习者假设处理，不为单次整理强行建档。

## 1. 盘点来源

列出文件类型、时间或周次、彼此关系和明显缺口。识别课堂原始材料、指定教材／论文、题目与答案、已有整理稿、外部补充五类来源。多文件、转写、扫描件和来源冲突的处理规则见 [source-and-output.md](source-and-output.md)。

对 PDF、幻灯片、表格、图片、音视频使用环境中可用的对应工具提取并核对；工具不可用或材料不可读时标明限制。文件存在不等于内容已读。

## 2. 建立单元画像

按 [course-routing.md](course-routing.md) 形成简短内部画像：知识形态、认知动作、主要与次要处理模式、目标任务、学习者基础与需要的脚手架。画像是生成决策，不要求原样写入成品；明显混合的单元分段路由。

## 3. 先做知识蓝图

在写长文前提取：

- 本单元真正要解决的问题；
- 3—8 个关键节点及其依赖、因果、对比或步骤关系；
- 老师反复强调、明确提示考试、题目实际使用或目标任务必需的内容；
- 学习者最可能混淆、跳步或误用的位置；
- 材料中的矛盾、疑似转写错误和缺少证据之处。

删除寒暄、课堂管理、重复口头禅和不服务于知识的故事。案例只有在解释概念、机制、判断或方法时才保留。

## 4. 按模式重构

读取 [mode-guides.md](mode-guides.md) 中命中的部分，用最少但充分的结构呈现：

- 共同核心：单元问题、知识地图、关键内容、易错点；
- 条件模块：理论机制、论证证据、公式例题、操作流程、文本解读、案例项目；
- 学习闭环：主动回忆／练习、自检反馈、快速复习。

只在“定义、意义、例子、作答方式”这类字段确实帮助理解或完成目标任务时使用它们。

蓝图中出现参数变化、动态过程、二维分类，或需要真实图像作为证据和辨认对象时，按 [visual-aids.md](visual-aids.md) 判断是否制作示意图、动效图、交互图或寻找真实图片。

## 5. 按需执行讲透增强

普通模式直接进入第 6 步。讲透模式按 [deep-explanation-mode.md](deep-explanation-mode.md) 从候选结构建立知识缺口图，调用可用的研究能力，建立主张—来源关系，重写为连续教学链，并执行多 Agent 或降级的分角色质询。检索失败时保留已达到普通底线的候选内容并说明缺口。

## 6. 设计练习

读取 [learning-design.md](learning-design.md)。题目数量服从内容密度，至少覆盖：提取一个关键事实、概念或步骤；解释一个关系或机制；在新例子或情境中应用；辨别一个常见错误或不成立条件。有学习项目时，至少一题直接对应本单元服务的目标任务。每题提供可核对反馈；开放题给答案要点或评分维度。

笔记中的练习供以后自测，答案集中放在练习之后。学习者要当场练习时，转入 [practice-and-feedback.md](practice-and-feedback.md) 的交互方式，另出笔记里没有的新题。

## 7. 写入结果

默认每个自然学习单元一个 Markdown 文件。存在学习项目或课后模式时写入 `02_notes/`；否则优先沿用项目现有命名和目录。默认结构按需增删：

1. 标题与一句话主线；
2. 单元地图；
3. 按知识关系组织的主体；
4. 模式专属内容；
5. 易错点与边界；
6. 主动回忆／练习及答案；
7. 快速复习页；
8. 待核实与补充来源（仅在需要时）。

讲透模式仍以一篇连续主笔记为中心；仅在实际开启时标记 `depth_mode: "deep"` 并附精简来源地图。输出规范、公式兼容和来源标记见 [source-and-output.md](source-and-output.md)。

存在学习项目时，写完后更新 `00_learner_state.md`：本单元节点至少记为“接触过”，把快速复习页的检索问题加入复习队列。读完笔记不构成更高等级的证据。

## 8. 验证

逐项检查，全部通过才算完成：

- **忠实度：** 关键结论能追溯到材料；推断和补充没有伪装成课堂原话。
- **结构：** 读者能看出知识之间的依赖、因果、对比或步骤，而非只有标题和定义。
- **覆盖：** 老师强调、教学目标、题目和目标任务的实际要求没有被降噪误删。
- **效率：** 已掌握内容被压缩，薄弱和高权重内容得到展开；与目标无关的延伸没有进入正文。
- **可练习：** 问题要求真实提取、解释或应用，并有反馈。
- **普通质量：** 未开启讲透模式时仍有必要解释、例子或应用、易错点和练习反馈。
- **讲透增强：** 开启时重要缺口得到处理，关键外部主张可追溯；未实际联网或使用多 Agent 时没有虚假声称。
- **课后归档：** 原始材料、转写、笔记和索引分离但使用一致的会话标识。
- **视觉素材：** 每张图都有学习用途；图中数值与正文一致；真实图片的出处和许可已核实并写在图下；交互或动效图有静态版本。
- **格式：** 对 Markdown 文件运行下方命令，表格、代码、图片、链接和公式可读。

```bash
python3 scripts/validate_learning_asset.py <文件或目录>
```

脚本只检查确定性问题：Markdown 与数学分隔符、本地图片和链接是否存在、SVG 是否可解析、HTML 是否引用外部脚本。它不能替代事实核对和视觉检查。
