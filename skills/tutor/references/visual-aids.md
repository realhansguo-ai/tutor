# 视觉素材：示意图、动效图、交互图与真实图片

视觉素材只在它让学习者更快看懂、记住或判断某件事时使用。每张图都要回答“学习者看完这张图能做到什么”；答不出就不放。装饰图、氛围图和泛泛的配图不进入笔记。

## 何时值得用

| 学习内容 | 合适的素材 |
| --- | --- |
| 变量之间的函数关系、比较静态、参数变化（供需移动、成本曲线、IS-LM、预算线、分布形状） | 交互图：学习者自己拖动参数；或动效图展示一次完整的变化过程 |
| 随时间展开的过程、机制、算法步骤 | 动效图或分步静态图 |
| 分类、定位与权衡（象限图、矩阵、二维比较） | 静态象限图；需要学习者自己定位时用交互图 |
| 结构、依赖、流程 | 静态示意图 |
| 原始证据本身（历史照片、油画、版画、地图、档案、广告、实物） | 真实图片，并当作史料来解读 |
| 需要学会辨认的真实对象（标本、仪器、岩石、建筑、解剖结构） | 真实图片 |

一张图只讲一件事。一个学习单元通常 0—4 张，同一张图的静态、动效、交互版本算一张；内容是纯定义或纯论述、图像不增加信息时不放图。真实图片要直接呈现本单元讨论的对象；只间接相关的图，只有在正文明确用它做对照（例如“外部视角与内部劳动的差别”）时才放。

## 一、生成示意图、动效图和交互图

### 选层级

按能达成学习目的的最低层级选择；只要做了动效或交互，就必须同时给静态版本。笔记中嵌入动效版或静态版之一，另一个放在同一目录并在图下链接，供打印或导出 PDF 使用：

1. **静态 SVG：** 默认层级，任何 Markdown 查看器都能显示。
2. **动效 SVG：** 用 SVG 内的 CSS 动画展示一次变化过程（例如需求曲线右移、价格走到新均衡）。嵌在笔记中自动播放，不需要脚本。单次循环 4—10 秒，在起止状态各停留约 1 秒，不闪烁。
3. **交互 HTML：** 学习者自己拖动参数探索，适合比较静态、参数敏感性和“如果……会怎样”。从 [../assets/interactive-figure-template.html](../assets/interactive-figure-template.html) 复制，只改 `FIGURE` 配置；模板支持函数曲线、竖直或任意 x(y) 曲线、标注点、读数、初始状态对照和象限图。模板放不下的图可以自写，但保持同样的约束。

### 设计规则

- **与正文同源：** 图中的方程、参数符号和数值与笔记正文一致；交点、均衡值等用与正文相同的公式计算，不凭目测画。
- **坐标完整：** 坐标轴名称和单位、刻度、曲线标签齐全；比较前后状态时保留初始状态作为浅色虚线。
- **范围合理：** 参数范围让曲线保持在可视区内，不产生负数量、负价格这类无意义状态；无法避免时在读数中说明。
- **先预测再看：** 笔记中在图前放一个预测问题（“需求增加时均衡价格怎样变化？先写下答案”），图后解释为什么。
- **自包含：** 交互 HTML 是单个文件，CSS 和 JS 内联，不引用 CDN、外部字体或网络资源，离线可用。
- **示意图标注：** 生成的图标注“示意图”，不暗示是真实数据；使用真实数据作图时注明数据来源。

### 在笔记中引用

依次写入三部分：

1. 预测问题，例如“**先预测：** 需求截距增加时，均衡价格和数量分别怎样变化？”；
2. 用 Markdown 图片语法嵌入静态或动效 SVG，替代文字写清图的内容并注明“示意图”，例如“需求增加时的均衡移动（动效示意图）”；
3. 交互版本的普通链接，链接文字写“打开可交互版本”，后面一句说明该拖动什么、对照什么。

素材放在笔记旁的 `assets/<笔记文件名去掉扩展名>/` 中；学习项目中即 `02_notes/assets/<笔记文件名>/`。文件名用简短英文或拼音描述内容。

### 验证

- 用独立计算（例如解方程）核对图中标出的每个关键数值；
- SVG 必须是格式良好的 XML；
- 环境中有浏览器时打开交互 HTML，逐个操作控件，确认图形和读数随之变化、控制台没有错误；浏览器不能执行本地文件中的脚本时，在素材目录用 `python3 -m http.server <端口> --bind 127.0.0.1` 临时提供访问，检查完立即停止该服务；没有浏览器时说明未做渲染检查；
- 运行 `python3 scripts/validate_learning_asset.py <笔记或目录>`，它会检查笔记中的本地图片和链接是否存在、SVG 是否可解析、HTML 是否引用外部脚本。

## 二、寻找真实图片

### 来源

优先使用能在文件页面上核实作者、年代、收藏机构和许可的来源：

1. Wikimedia Commons（文件页列出作者、日期、来源和许可）；
2. 博物馆和图书馆的开放获取馆藏，例如大都会艺术博物馆 Open Access、芝加哥艺术博物馆、荷兰国立博物馆、史密森尼 Open Access、美国国会图书馆 Prints & Photographs、各国国家档案馆；
3. 政府和科研机构的公共领域图像，例如 NASA、NOAA。

使用环境中可用的联网、搜索或浏览能力。不能联网时，说明需要什么图、建议到哪类馆藏查找，不编造图片或链接。

### 核实

- 打开图片所在的原始页面核对标题、作者、年代、收藏机构或出处和许可；搜索结果摘要和缩略图不算核实。书籍插图、版画没有收藏机构时，写原出版物及扫描提供者；有多层归属（绘者、刻工、出版物）时全部写出。
- 历史照片和画作常有错误归属或错误年代：以收藏机构页面为准。机构页面因拦截、登录或付费墙打不开时，不设法绕过，改用文件页和机构合作页面（如 Google Arts & Culture）核对并注明“机构页面未能打开”；作者或年代仍无法核实时，标“归属待核实”，或换一张能核实的图。
- 多个来源不一致时在说明中标“归属待核实”。
- 确认图片确实呈现了正文要说明的内容；只是主题相关不够。
- 不使用 AI 生成或自己绘制的图像冒充真实照片或文物。

### 许可

| 许可状态 | 处理 |
| --- | --- |
| 公有领域、CC0 | 可以下载使用，仍注明出处 |
| CC BY、CC BY-SA | 可以下载使用，按要求署名并注明许可 |
| CC BY-NC 等非商业许可 | 可用于个人学习笔记，注明许可；笔记要公开或商用时提醒用户 |
| 所有权利保留、许可不明、带水印的图库图片 | 不下载、不嵌入；在笔记中给出原页面链接和文字描述 |
| 不同来源的许可说法冲突 | 按较严格的说法处理：个人学习笔记可使用并在图下注明冲突；笔记要公开或商用前提醒用户向收藏机构确认 |

下载遵守当前环境的权限规则。保存到笔记的 `assets/` 目录，宽度 1600 像素左右即可；Wikimedia Commons 等来源提供合适尺寸的缩略图地址时优先使用，不保存超大原图。

不能下载时，用来源提供的稳定缩略图地址远程嵌入，图下说明不变，并在待核实一节注明“远程嵌入，离线不可见；格式检查脚本不检查远程地址”。之后获得下载条件时再保存到 `assets/` 并改为本地路径。

### 当作史料解读

真实图片进入笔记时，图下写说明，图后写解读：

```text
（Markdown 图片语法，替代文字写图片标题和年代）
*图：标题／作者／年代／收藏机构或扫描提供者／许可，来源：原始页面链接，访问于 2026-10-15*
**读图：** 这张图由谁、为何而作？它能作为什么的证据？它不能证明什么？
```

画作是作者的诠释，不是照片：说明创作背景和可能的立场，例如浪漫化、宣传或批判。老照片可能经过摆拍、裁切或后期加工。解读服务于本单元的问题，例如用工厂版画讨论工厂制的空间组织，而不是写成艺术鉴赏。
