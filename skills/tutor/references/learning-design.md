# 学习、练习与复习设计

本文件约束如何把“可读笔记”变成“可学习资产”。这些原则用于改变题目和结构，不用于在成品中堆砌学习科学术语。

## 1. 检索先于重读

至少设计一次不看材料的提取：自由回忆、简答、列步骤、画关系、判断方法或完成例题。随后必须给反馈，让学习者纠正遗漏和错误。

不要把所有内容都做成识记卡。定义、术语、符号和顺序适合短检索；机制、论证和方法要用解释、应用或诊断题检索。

## 2. 从被动阅读升级为生成

参考 ICAP 的区分，让学习者产生材料中没有原样给出的输出，例如：

- 用自己的话解释；
- 画出因果或步骤关系；
- 生成一个新例子或反例；
- 预测条件改变后的结果；
- 找出论证缺口；
- 与同伴比较解法或共同修订答案。

互动任务只有在用户需要课堂活动或小组学习时才生成；个人笔记至少做到建构性活动。

## 3. 间隔与交错按条件使用

- 需要长期保持时，把关键问题做成可在以后重新作答的复习题；不要承诺一个对所有人都最优的固定间隔。学习项目中的复习安排见 [learner-state.md](learner-state.md)。
- 当学习者必须识别“该用哪一种概念、题型或方法”时，混合相近类型进行交错练习。
- 新手尚未掌握基本步骤时，先完成清楚示范和同类练习，再增加交错；不要用随机混排制造无效困难。

## 4. 新手使用 worked examples

对多步骤计算、证明、实验、代码和操作流程：

1. 展示一个完整示例，解释每个关键选择；
2. 给一个缺少部分步骤的完成题；
3. 给独立题；
4. 给需要先判断方法的迁移题。

随着熟练度提高撤去脚手架。不要让熟练学习者重复阅读大量显而易见的步骤。

## 5. 抽象与具体相互连接

概念或公式至少连接一个真实、典型且不误导的例子；例子必须回扣抽象结构。图表、流程图、时间线或对比表只有在能表达关系时使用，不能只作装饰。

## 6. 深层问题与反馈

问题数量由内容决定。短单元通常 6—10 题即可，复杂单元可以更多；宁可覆盖关键关系，也不要凑满固定数量。

建议覆盖矩阵：

| 层次 | 问题形式 | 反馈形式 |
| --- | --- | --- |
| 提取 | 写出术语、条件、步骤或公式 | 精确答案与遗漏点 |
| 解释 | 为什么、如何发生、关系是什么 | 逻辑链或必要要点 |
| 应用 | 新数字、新材料、新情境 | 步骤、选择依据与结果 |
| 辨错 | 哪里错、为什么错、怎样改 | 错误位置、机制与改法 |
| 迁移／评价 | 条件改变、比较方案、判断证据 | 评价标准、合理答案范围 |

选择题必须让干扰项对应真实误解，并解释错误选项错在哪里。开放题提供答案要点、评分维度或自检清单；材料无法支持唯一答案时明确允许多解。

## 7. 快速复习不是再次全文摘要

快速复习页优先包含：

- 单元的一条主线；
- 必须能闭卷提取的最小知识；
- 2—5 条关键关系、判断或步骤；
- 最容易犯的错误；
- 3—5 个能够重建整节课的检索问题。

“必背、必懂、必会”只在内容确实能够这样区分时使用。没有教学大纲或真题支持时，不写“必考”。

## 研究边界

采用的证据方向包括：检索练习、分散学习、交错练习、深层解释问题、抽象与具体连接、worked examples 与生成性参与。研究结果通常受知识类型、学习者基础、反馈和任务条件影响，因此本 Skill 使用条件规则，不把某一种技巧写成普遍最优。

主要依据：

- Pashler 等的美国教育科学研究院实践指南 [*Organizing Instruction and Study to Improve Student Learning*](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：间隔、例题与解题交替、图文结合、抽象与具体连接、测验和深层解释问题。
- [Dunlosky 等对十种学习技巧的综述](https://pubmed.ncbi.nlm.nih.gov/26173288/)：练习测试与分散练习具有较广泛效用，其他方法需要结合条件。
- [Chi 与 Wylie 的 ICAP 框架](https://doi.org/10.1080/00461520.2014.965823)：建构性和互动性活动要求学习者生成超出材料表面的内容。
- [worked-example 研究综述](https://doi.org/10.1007/s10648-010-9145-4)：复杂任务的初学阶段，完整示例和逐步撤架通常优于无指导的问题求解；该优势会随已有知识变化。
