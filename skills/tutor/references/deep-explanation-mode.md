# 讲透模式

讲透模式是叠加在学习单元、练习批改、复习和建档等环节上的可选增强层。它在普通课程笔记已经达到忠实、清楚、完整、可练习的基础上，增加针对性外部研究、证据集成、多轮质询和深度控制。目标不是写得最长，而是让当前学习单元的关键知识链闭合，学习者能够解释、区分、应用并知道边界。

## 开启与作用域

默认关闭。只有用户明确确认才开启；“开启讲透模式”“把这个彻底讲透”“结合外部资料完整研究”“深挖并多轮检查”等明确表达本身就是确认，不再重复询问。

Agent 可以在确有价值时建议一次，并同时说明增加的研究范围、时间或来源工作；用户未确认时继续普通模式。默认只对当前任务生效，只有用户明确要求才设为整门课程或后续任务的默认值。

讲透模式不改变原任务的授权边界，也不自动扩大课程范围。若“一节课”可能扩展为整章、整门课或另一考试体系，先确认边界。

## 与普通模式的关系

普通模式不是简陋模式。不开启讲透模式时，仍须满足 `SKILL.md` 的忠实度、结构、学习活动、易错点和来源边界要求。讲透模式只增加以下工作：

- 围绕知识缺口开展更广泛的外部研究；
- 把不同类型来源集成为一条教学链；
- 对候选笔记进行角色化、多轮质询；
- 根据重要性和学习者状态动态增减解释；
- 为关键外部结论建立更完整的可追溯关系。

## 工作流

### 1. 固定任务锚点

先从课堂材料、考试范围、用户笔记或当前问题中确定：学习者要解决什么、需要做到什么、哪些内容属于本单元。外部研究服务于这个锚点，不得把课程笔记改写成泛泛的百科综述。

先形成一份达到普通模式质量底线的候选结构，再判断它缺少什么。这样即使检索失败，结果也不会退化为空壳。

### 2. 建立知识缺口图

只记录会影响理解或使用的缺口，可从下列角度选择：

- 前置知识是否缺失；
- 定义、对象和问题边界是否清楚；
- 机制、因果链、推导或操作理由是否断裂；
- 关键结论是否缺少证据；
- 是否缺少一个完整例子、反例或对比例；
- 是否容易与相近概念、相似题型或邻近方法混淆；
- 适用条件、失败条件和争议是否被隐藏；
- 学习者能否迁移到新题目、新材料或真实任务；
- 课堂说法是否需要核实、纠错或更新。

每个缺口都应对应一个预期用途。没有用途的搜索不启动。

### 3. 调用可用的搜集能力

按当前环境选择能力，不绑定固定工具：

1. 优先使用 Agent 已有的网页、学术、代码、数据库或连接器能力；
2. 存在专门的搜索、研究、文献或平台 Skill 时，读取并按其规则调用；
3. 没有专门 Skill 但能够联网时，自行设计关键词、来源组合和核查路线；
4. 不能联网时，使用用户材料、本地文献和可验证的已有知识完成可完成部分；
5. 权限、登录、付费墙或工具缺失阻断关键证据时，说明限制，只在用户能够提供材料或授权会改变结果时询问。

不得绕过权限、伪造访问结果、把搜索摘要当作已阅读全文，或在未使用多 Agent 时声称已经完成多 Agent 质询。

### 4. 按缺口匹配来源

来源是否“优秀”取决于它在当前笔记中承担的作用，而不是名气、排名或语言。优先判断相关性、权威性、可核验性、解释增益、时效性和可复现性。

| 需要解决的问题 | 优先来源 |
| --- | --- |
| 事实、定义、标准和原始结论 | 原始论文、官方文件、标准、权威数据库、指定教材 |
| 学科结构和研究共识 | 高质量教材、系统综述、领域综述 |
| 难点的直觉解释 | 优秀课程、专业博客、研究者讲解 |
| 代码、实验和操作 | 官方文档、维护良好的开源仓库、可运行示例 |
| 真实错误和失败条件 | issue、勘误、复盘、技术讨论、反例 |
| 争议和替代解释 | 原始批评、回应论文、不同学派的代表性材料 |
| 迁移和应用 | 高质量案例、题目、项目或领域实践 |

“隐藏的大神文章”可以提供独特直觉、经验和问题意识，但不能仅凭作者声望成为关键事实的唯一依据。检查其论证、引用链、可复现内容和适用条件；无法独立核实的经验应保留为有归属的实践观点。

### 5. 建立主张—来源关系并重新讲授

外部材料进入正文前，先在内部确定它支持哪个主张、承担什么作用、是否存在冲突。关键事实和纠错结论至少要有与其重要性相称的证据；来源之间冲突时不以数量投票，比较证据层级、研究对象、时间和适用条件。

最终正文不按“来源一、来源二”拼贴，而要重构为连续教学链：

```text
问题为什么出现
→ 需要哪些前置知识
→ 核心概念和关系
→ 机制、推导或步骤
→ 完整例子
→ 易错点、反例和边界
→ 如何迁移到新任务
```

课堂材料仍是课程任务的主轴。补充资料用于解释、验证、纠错和拓展，不得淹没老师的教学路线。课堂与可靠外部知识冲突时，分别说明各自表述、可能原因以及考试作答和实际理解如何处理。

### 6. 对候选笔记执行“拷问”

运行环境允许多 Agent 且用户已开启讲透模式时，使用多 Agent 对同一份候选笔记进行角色化质询。“允许”同时指技术上能启动子 Agent，以及平台或用户规则没有要求另行授权；规则要求用户明确要求才能启动子 Agent 时，先征得同意，未同意即按下文降级。根据任务选择最少但互补的角色，例如：

- **初学者审查：** 哪些地方表面流畅，但缺前置解释或例子？
- **学科审查：** 定义、机制、推导、条件和反例是否准确？
- **证据审查：** 哪些主张没有被来源支持，或把弱来源用得过重？
- **应用审查：** 学习者是否真的能做题、分析材料、执行步骤或迁移？
- **删减审查：** 哪些内容重复、跑题或只增加篇幅？

各 Agent 的任务是指出可定位的缺口、证据和修改建议，不是各写一份互不相干的笔记。由主 Agent 比较质询意见并负责最终取舍；共识不能替代证据，少数意见若提出有效反例也必须处理。

若当前 Agent 不支持多 Agent，则由同一 Agent 分离角色、分轮审查并如实说明降级，不伪装成多 Agent。不要向用户展示隐藏推理过程；只保留必要的结论、修改和未解决分歧。

质询轮次自适应：只要新一轮仍发现影响正确性、理解或迁移的实质缺口，就继续；若没有新增关键问题，或新增讨论只是重复和偏题，就停止。不得为了展示“多轮”而强行争论。

### 7. 控制解释深度

每个知识节点的展开程度由以下因素共同决定：

- 对本单元目标的重要性；
- 是否是后续知识的前提；
- 学习者是否容易误解；
- 课堂材料是否解释不足；
- 是否需要推导、示例或操作才能理解；
- 是否会在考试或实践中反复使用；
- 结论的不确定性、争议和风险。

重要、困难、易错、可迁移的内容多讲；次要、重复、仅作背景的内容少讲；与当前目标无关的内容不讲。对新手先给完整示例和脚手架，再转向独立解释与应用；对已有基础者压缩显然步骤，把篇幅用于比较、边界和迁移。

### 8. 决定引用、回原文和询问

应引用或链接：外部研究结论、精确数据、可变化事实、原始定义和标准、争议观点、直接引语、课堂纠错依据，以及博客或开源资料中的独特方法。普通教学过渡、自建示例和已经标明来源后的直接推演不必逐句引用。

当措辞影响含义、公式或限定条件可能被摘要丢失、多个来源冲突、需要解释作者论证或核对老师原意时回到原文。已经核实且只需教学性重组时，不为形式上的“忠于原文”反复引用难懂段落。

只有答案会改变研究路线、学习层级、课程范围、考试体系或授权边界时才询问用户。能够从材料可靠判断、可以并列说明或能通过检索解决时直接完成。

## 输出与来源记录

内部可以有搜索记录、缺口图和质询意见，最终交付仍以一篇连续、可独立学习的主笔记为中心，不交付资料清单或争论日志来代替讲解。

有 frontmatter 时，仅在实际开启后增加：

```yaml
depth_mode: "deep"
```

正文按需使用轻量边界标记，例如“课堂重点”“补充解释”“研究证据”“实践经验”“争议／边界”“待核实”；正常的综合叙述不必逐句贴标签。末尾保留精简的“来源地图”，至少让关键外部主张能够追溯到来源及其用途。

课后模式中，若外部研究较多或网页具有时效性，可在对应会话包中增加 `research.md`，记录查询日期、链接、来源类型、支持的主张和未解决冲突；它是研究记录，不放进 `originals/`，也不替代主笔记中的必要引用。

## 完成判据与停止条件

讲透模式在以下条件满足后停止：

- 当前单元的关键知识链已经闭合；
- 重要缺口已经解释，或明确标为待核实；
- 核心外部主张有与其重要性相称的来源支持；
- 至少有一个完整例子、应用或材料分析；
- 关键误解、反例、适用条件和失败条件已经覆盖；
- 学习者能够不看原文复述、解释并使用核心内容；
- 质询不再产生新的实质问题；
- 新来源只增加重复说法、背景趣闻或偏离目标的延伸。

无法获得关键证据时，不宣称已经“完全讲透”；交付当前可验证的最佳版本，并明确缺口和它对结论的影响。

## 在不同学习任务中的取舍

- **课后模式：** 课堂内容是主轴，优先补老师跳过的前置、机制、完整例子和易错点。
- **临近考试：** 以考纲、真题和评分任务为锚，只讲影响高频判断与作答的深层关系，压缩低收益背景。
- **复习与错误修复：** 以 `00_learner_state.md` 中的错误记录和反复出错的节点为锚，重点修复误解、补齐前置、建立迁移比较。
- **系统学习：** 以领域地图中的节点和目标任务为锚，可以扩大理论脉络、证据争议和跨场景应用，但仍按单元停止。

## 设计依据

- [Lewis 等，Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://proceedings.nips.cc/paper/2020/hash/6b493230205f780e1bc26945df7481e5-Abstract.html)：外部可更新知识和来源可追溯能够补足仅依赖模型内部知识的限制；检索到资料不等于资料天然正确。
- [Du 等，Improving Factuality and Reasoning in Language Models through Multiagent Debate](https://proceedings.mlr.press/v235/du24e.html)：多实例、多轮批评可改善部分推理和事实任务；本模式据此采用角色化质询，但不把共识当证据。
- [美国教育科学研究院，Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：完整例题与独立练习交替、深层解释问题、主动提取和随熟练度撤架支持循序渐进的教学控制。
