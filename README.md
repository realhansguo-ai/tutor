# tutor

一个帮你系统学会某个领域知识的 Agent Skill。它不只是把资料整理成笔记，而是带你走完一个学习闭环：

```text
定目标、画知识地图、诊断起点
  → 按单元学习（整理课堂录音、讲义、教材）
  → 出题、批改、定位错因
  → 间隔复习
  → 阶段验收（模拟考试或迁移任务）
  → 根据结果调整路线
```

学会与否以你在没见过的题目或任务上的表现为准，不以读完、看懂或自评为准。

## 安装

```bash
npx -y skills add realhansguo-ai/tutor -g --all
```

## 怎么用

安装后直接用自然语言说：

- “我想在两个月内自学因果推断，目标是读懂经济学论文里的识别策略。帮我开始。”
- “这是今天计量课的录音转写，用课后模式整理成笔记。”
- “考考我遗漏变量偏误。”
- “这是我的答案，帮我批改。”
- “今天复习什么？”
- “我准备好期中考试了吗？”
- “开启讲透模式，把这一节彻底讲透。”

长期学习时，它会在你的工作目录里建一个学习项目：

```text
00_learning_plan.md   目标任务、领域地图、学习路线、留出验收题
00_learner_state.md   掌握等级、错误记录、复习队列
02_notes/             单元笔记
03_practice/          练习与批改记录
04_checks/            阶段验收卷和报告
```

下次打开时从这些文件接着学。只想整理一次资料时，不会强制建项目。

## 适用范围

- **适合：** 概念、理论、方法、论证、计算和程序性知识，例如一门大学课程、一场考试、一个研究方向。
- **不适合：** 语言习得、乐器、运动等靠长期练习积累的技能；脱离学习内容的纯日程安排；代写需要你独立完成的作业或考试。
- “讲透模式”会联网补充外部资料并多轮自查，耗时更长，只在你明确要求时开启。

## 运行依赖

- 支持 Agent Skills 的客户端（如 Claude Code、Codex）
- Python 3，只用标准库（用于课后归档、课程索引和笔记格式检查）
- 笔记中的公式同时兼容 Obsidian 与 GitHub

## 当前状态

测试版。完整流程已在多个学科（计量经济学、历史、编程、考试写作）上由 Agent 模拟学习者跑通，还没有经过大量真人长期使用。遇到问题欢迎提 Issue。
